# Curio Privacy Policy

This public repository is the single deployable source for Curio's bilingual privacy policy and support page. It intentionally stays separate from the private application source repository.

Published pages:

- https://ssdiwu.github.io/curio-privacy/
- https://ssdiwu.github.io/curio-privacy/support/

The `main` branch is the configured GitHub Pages source. Keep the privacy policy, support email, and public links aligned with Curio's app source and App Store Connect metadata before publishing a release.
